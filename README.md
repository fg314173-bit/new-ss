# Bite&Go 🍽️

Smart locker food ordering system for NU.

## Setup

```bash
npm install
npm start
```

Open http://localhost:3000

## Architecture

- **index.html** - Full SPA (student + staff views)
- **server.js** - Express API + static server
- In-memory data (orders persist during session)
